Model 2 is a one-dimensional convolutional network (1D-CNN) on the raw windows: 128 time steps of the 9 standardised inertial channels, treated as input channels. Five convolutional blocks follow, each a 1D convolution that keeps the sequence length, batch normalisation and a ReLU. The blocks have 64, 64, 128, 128 and 128 filters with kernels of 5, 5, 5, 5 and 3 samples, and max pooling by 2 after the second and fourth blocks shortens the sequence from 128 to 32 steps, so each position of the last block sees 36 consecutive samples (0.72 s). Global average pooling over time, dropout and a linear layer produce the six class logits.

The tuning grid ({{table:tuning}}) varied the dropout rate and the first two kernel widths (5 or 7 samples). All four configurations scored within the 0.001 tie margin on validation, so the tie rule chose the fewest parameters and then the default: configuration {{tuning:cnn1d:config_id}}, with dropout {{tuning:cnn1d:dropout}}, {{tuning:cnn1d:params}} trainable parameters and a validation macro-F1 of {{tuning:cnn1d:val_macro_f1}} on seed 42. Training follows the shared protocol of Section V.

A convolution applies the same filters at every position of the window, and global average pooling discards where a pattern occurred, which suits the repeating steps of the walking activities. Convolution over raw multichannel signals learns useful features for activity recognition [@yang2015], and a deep 1D convnet on raw UCI HAR signals reached 94.79% test accuracy [@ronao2016], the published setup closest to ours; a survey also found convolutional networks the strongest family on this dataset [@wang2019]. Model 2 tests how far features learned from the raw signal go against the hand-crafted ones of Model 1 on unseen subjects.
