Model 3 is a bidirectional long short-term memory network (BiLSTM) [@hochreiter1997; @schuster1997] on the raw windows: 128 time steps of the 9 standardised inertial channels. Two stacked bidirectional LSTM layers with 64 units per direction read the window from both ends, so the representation of each time step depends on the samples before and after it. Dropout is applied between the two layers and again before the output. The window is summarised either by the final forward and backward hidden states of the top layer, concatenated ("last" pooling), or by the mean of the top layer's outputs over all time steps ("mean" pooling). A linear layer produces the six class logits.

The GRU ablation keeps everything except the cell, replacing each LSTM with a gated recurrent unit [@cho2014]. A GRU merges the LSTM's separate memory cell into its hidden state and uses two gates instead of three, so the same network has fewer parameters. It is an ablation of Model 3, not a fifth family: it asks whether the LSTM's memory cell and extra gate matter on windows of only 2.56 s.

Both networks were tuned on the same grid ({{table:tuning}}) of dropout rate and pooling. All four configurations of a network have the same parameter count, so validation macro-F1 alone decided. The BiLSTM kept its default, configuration {{tuning:bilstm:config_id}} (dropout {{tuning:bilstm:dropout}}, {{tuning:bilstm:pooling}} pooling, {{tuning:bilstm:params}} parameters, validation macro-F1 {{tuning:bilstm:val_macro_f1}} on seed 42). The GRU selected configuration {{tuning:gru:config_id}} (dropout {{tuning:gru:dropout}}, {{tuning:gru:pooling}} pooling, {{tuning:gru:params}} parameters, validation macro-F1 {{tuning:gru:val_macro_f1}}). Training follows the shared protocol of Section V.

Recurrence suits activity recognition because walking and its stair variants are defined by the order and rhythm of steps, which a recurrent network carries from one time step to the next. A residual bidirectional LSTM reached 93.6% on UCI HAR [@zhao2018] and a four-layer LSTM 96.7% [@murad2017], and in a comparison across families the bidirectional LSTM was best on OPPORTUNITY [@hammerla2016]. Model 3 tests whether recurrence keeps this advantage when the test subjects are never seen in training.
