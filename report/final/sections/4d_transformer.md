Model 4 is a Transformer encoder [@vaswani2017] on the raw windows: 128 time steps of the 9 standardised inertial channels. A linear layer projects each time step to 64 dimensions, and a learned positional embedding (one vector per time step) is added so that the model can use the order of the samples. Three encoder layers follow, each with four-head self-attention and a feed-forward block with GELU activation. The layers are pre-norm, with layer normalisation before each sub-layer, which kept training stable at the shared learning rate without a warm-up schedule. A final layer normalisation, the mean over the 128 time steps and a linear layer produce the six class logits.

The tuning grid ({{table:tuning}}) varied the dropout rate, applied to the embeddings and inside every encoder layer, and the width of the feed-forward block. Configuration {{tuning:transformer:config_id}} was selected, with dropout {{tuning:transformer:dropout}} and a feed-forward width of {{tuning:transformer:dim_feedforward}}, giving {{tuning:transformer:params}} trainable parameters and a validation macro-F1 of {{tuning:transformer:val_macro_f1}} on seed 42. One configuration with the wider feed-forward block scored marginally higher on validation, but within the 0.001 tie margin, so the tie rule chose the smaller model. Training follows the shared protocol of Section V.

Self-attention lets every time step attend to every other one within a single layer, so the model can relate distant parts of the window directly instead of passing information step by step as a recurrent network does. Attention-only models have been applied successfully to other wearable datasets [@mahmud2020; @dirgova2022], but the second used a random split that is not subject-wise. Model 4 tests whether attention over the whole window can replace recurrence and convolution when the evaluation is subject-independent and only 15 subjects are available for training.
